# 🇰🇷 대한민국 대통령 시뮬레이터

2025년 6월 4일 취임한 대한민국 제21대 대통령이 되어 5년 임기를 운영하는 AI 채팅 시뮬레이션 게임.

## 핵심 특징

- **AI 채팅 기반 결정**: OpenAI API로 비서실장과 대화하고, 대통령의 결정에 대한 정치·경제·사회 파급효과를 AI가 산출
- **상세 지표 대시보드**:
  - 지지율 (전체 / 연령별 / 지역별 / 이념별 / 성별 / 정당 지지층별)
  - 경제 (GDP, 물가, 실업, 환율, 코스피/코스닥, 무역수지, 국가/가계부채, 주택가격, 소비/기업심리)
  - 사회 (출산율, 자살률, 의료/교육/연금 만족도, 젠더·세대 갈등, 미세먼지, 언론자유)
  - 안보 (DEFCON, 북한 긴장도/도발위험, 군 준비태세, 한미동맹, 사이버/테러 위협)
  - 외교 12개국 (관계도·신뢰도·교역량)
  - 국회 22대 의석 분포 (8개 정당)
  - 내각 23명 (충성·능력·여론·스캔들 리스크)
  - 11개 언론사 (성향·영향력·호의도)
- **AI 자동 이벤트 생성**: 턴 진행 시 한국 정치 맥락에 맞는 뉴스 이벤트가 생성되고, 대형 사건은 대통령이 선택지에서 대응
- **다중 저장 슬롯**: IndexedDB 기반, 무제한 저장/불러오기
- **빠른 행동 20+종**: 민생지원금, 부동산 규제, 검찰개혁, 원전 정책, 의대 정원 등

## 기술 스택

- Vite + React 18 + TypeScript + Tailwind
- zustand (상태) / idb (IndexedDB) / recharts (차트)
- OpenAI Chat Completions API (BYOK - 사용자가 직접 키 입력)
- 저장: localStorage(현재 세션) + IndexedDB(저장 슬롯)

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 열고, 시작 화면에서 OpenAI API 키를 입력하세요.

## 플레이 팁

- 좌측: 거시 지표 (지지율·경제·사회)
- 중앙: 비서실장과 대화 & 빠른 행동
- 우측: 이벤트·외교·안보·국회·내각·언론
- 상단 "1주 진행" 버튼으로 시간을 흘려보내면 AI가 이벤트를 생성
- 채팅창에서 **대화 모드**는 협의·질문(지표 변화 없음), **결정 모드**는 즉시 효과 반영
